# MOT – Magyar OkosTankönyv

Nyisd meg az `index.html`-t (vagy GitHub Pages-en a főoldalt).

- `data/konyvek.js` – tankönyvek, fejezetek
- `assets/css/style.css` – kinézet
- `assets/js/` – működés (`3d.js`: 3D jelenetek)
- `assets/vendor/` – mxGraph (Apache 2.0), three.js (MIT)
- `6.osztaly/` – tankönyv-PDF-ek fejezetenként; könyvenként egy `okostankonyv.html`, amelyben a tananyag, az interaktív feladatok és (a Természettudományban) a 3D animációk is benne vannak. A teljes `…__teljes.pdf`-et az okostankönyv betölti – ne nevezd át! (Angol és Hittan: önálló `feladatok.html`.)
